## ✨ 核心功能

- **游客可用**：未注册即可浏览地图、加载公共图层、下载公共数据
- **轻注册**：首次使用发布/收藏/关注/评价时才引导完善个人信息（一次即可）
- **离线数据包**：按区域下载公共摆摊数据，本地缓存无网可用
- **内容安全**：全部 UGC（发布/评价/昵称/个人信息）接入 `security.msgSecCheck`
- **管理员后台**：审核 + 可视化数据管理（`adminOpenids` 环境变量白名单鉴权）

## 🛠️ 技术栈

- **前端**：微信小程序原生（WXML/WXSS/JS），UI 遵循 Apple HIG 风格
- **后端**：微信云开发（云函数 + 云数据库 + 云存储），无自建服务器
- **数据库**：`spots`（点位，GeoJSON 地理索引）/ `users` / `favorites` / `follows` / `reviews` / `resources`
- **定位**：`wx.getLocation` + `wx.chooseLocation`，2dsphere 地理查询

## 🚀 快速开始

1. 微信开发者工具导入本项目（需开通云开发环境）
2. `cloudfunctions` 下各函数右键 →「上传并部署：云端安装依赖」（部署清单见 `docs/发布前检查清单.md`）
3. 云开发控制台创建集合并按清单建索引（重点：`spots.current.location` 2dsphere）
4. `manageSpots` 云函数配置环境变量 `adminOpenids`（管理员 openid，逗号分隔）
5. 公众平台配置用户隐私保护指引（位置信息/头像/昵称/手机号）
