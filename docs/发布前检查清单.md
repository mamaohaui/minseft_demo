## 〇、本轮新增功能（2026-08-28）

- **个人信息（原「经营资料」）**：游客身份可直接浏览地图、加载公共图层、下载公共数据；**首次使用受限功能（发布地点/资源、收藏、关注、写评价）时才引导完善**，保存至 `users` 集合（openid 为 _id）。字段：微信头像（open-type=chooseAvatar 选头像上传云存储）、昵称（input type=nickname 一键同步微信昵称，选填）、**电话（必填，号段强校验 /^1[3-9]\d{9}$/，前端+云端双重校验）**、是否有车辆（选填）、主要销售品类（选填）。我的页「个人信息」栏显示：未完善 → 「游客」+「未完善」角标；已完善 → 微信头像 + 昵称（未设置昵称则显示姓名）。点击该栏进入填写/编辑页。
- **数据管理（管理员可视化）**：我的 → 管理员 → 数据管理，可视化列表/编辑/删除云端点位（公共基础库 + 用户发布），修改即时生效，无需进云开发控制台。
- 配套：`getUser` 返回 `profileCompleted` 注册标记；`saveUserProfile` 保存个人信息并回填名下发布点 creatorName；`manageSpots` 接内容安全检测。

## 三、隐私与合规（微信公众平台 mp.weixin.qq.com）

1. **用户隐私保护指引**：左侧「设置 → 服务内容声明 → 用户隐私保护指引」，声明收集：
   - 位置信息（wx.getLocation / wx.chooseLocation，用途：查找附近摆摊地点、选择发布位置）
   - 头像（chooseAvatar 选择，用途：个人信息展示。收集方式为「用户主动选择」）
   - 昵称（input type=nickname，用途：展示发布者昵称。收集方式为「用户自行填写」）
   - **手机号**（用途：个人信息中保存联系方式，用于摊友间联系。收集方式为「用户自行填写」，选「开发者收集」为是）
   - 未声明对应权限时，调用隐私接口会被平台拦截。
2. **隐私弹窗**：小程序已内置 `components/privacy-popup`（地图页 / 发布页），基础库 ≥ 2.32.3 自动弹出。
3. **手机号页面提示（已实现）**：个人信息页电话字段下已显示「手机号仅用于摊友间联系与安全核实，不会向其他用户公开」，提交按钮下方显示「提交即表示同意《用户隐私保护指引》中的信息收集规则」——这是微信小程序收集用户自填手机号最常见的合规提示方式。电话准确性采用号段强校验（1[3-9] 开头 11 位）；如需 100% 实名准确性，企业主体可升级接入「手机号快速验证组件」（open-type=getPhoneNumber），个人主体不支持。
3. **类目**：确保小程序服务类目与「摆摊信息/生活服务」相符，否则审核可能被驳回。
4. **UGC 安全**：发布/评价/资源/昵称/个人信息均已接入 `security.msgSecCheck`，risky/review 一律拦截。

## 五、提交审核前自测

1. 清缓存后冷启动：地图定位授权 → 隐私弹窗 → 游客可直接浏览地图与公共图层，**无注册弹窗打扰**
2. 个人信息流程：游客点击「收藏 / 关注 / 发布地点 / 写评价」→ 弹「请先完善个人信息」→ 进入填写页：选微信头像（上传云存储）、昵称（type=nickname 一键带出微信昵称）、**电话必填（输入错误号段应提示）**、车辆/品类可选填 → 保存成功；我的页「个人信息」栏显示微信头像 + 昵称且无「未完善」角标；未完善时显示「游客」+「未完善」
3. 头像上传：填写页点头像 → 选择微信头像 → 提示上传成功；保存后我的页头像即时显示
4. 发布地点 → 管理员审核通过 → 地图显示
5. 发布含违规词内容（如测试敏感词）→ 应提示「内容包含违规信息」
6. 评价、收藏、关注、资源发布、昵称修改全链路
7. 公共数据下载：全部下载成都 → 44 个点位 → 地图公共图层
8. **数据管理（管理员）**：我的 → 管理员 → 数据管理 → 公共基础库 tab 看到点位列表 → 编辑一条（改标题/坐标）→ 保存后重新下载该区域验证生效；用户发布 tab 下架/恢复一条；删除一条基础点位后再下载验证消失
