## 三、隐私与合规（微信公众平台 mp.weixin.qq.com）

1. **用户隐私保护指引**：左侧「设置 → 服务内容声明 → 用户隐私保护指引」，声明收集：
   - 位置信息（wx.getLocation / wx.chooseLocation，用途：查找附近摆摊地点、选择发布位置）
   - 昵称（用途：展示发布者昵称）
   - 未声明对应权限时，调用隐私接口会被平台拦截。
2. **隐私弹窗**：小程序已内置 `components/privacy-popup`（地图页 / 发布页），基础库 ≥ 2.32.3 自动弹出。
3. **类目**：确保小程序服务类目与「摆摊信息/生活服务」相符，否则审核可能被驳回。
4. **UGC 安全**：发布/评价/资源/昵称均已接入 `security.msgSecCheck`，risky/review 一律拦截。
